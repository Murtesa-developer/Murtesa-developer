# 💫 About Me:
I'm Murtesa, a full-stack developer and automation engineer specializing in building intelligent bots and backend systems. I create custom bots for Discord, Telegram, Minecraft, and Roblox, integrate complex APIs across platforms like YouTube, TikTok, Google, and develop powerful AI agents for tasks like system monitoring, order handling, FAQ answering, and smart chatbot logic with memory.<br><br>I also build desktop applications with control panels for Windows, Android apps, and Firebase-powered full-stack systems that connect frontend and backend in real time. With hands-on experience in Python, JavaScript, Java, Bash, C#, and HTML, I deliver scalable, cross-platform tools for developers, businesses, and communities.<br><br>
